ID: FEAT-030 Feature
OPTIMIZARE PERFORMANȚĂ

Prezentare generală

Optimizarea performanței SOLR este esențială pentru a asigura timpi de răspuns rapizi și o experiență fluidă pentru utilizatorii peviitor.ro. Această funcționalitate acoperă configurarea cache-ului, thread pool-ului, monitorizarea performanței și alertarea la degradare.

Optimizare cache

Cache Descriere Dimensiune recomandată
filterCache Cache pentru rezultatele filtrelor 10000 intrări
queryResultCache Cache pentru rezultatele interogărilor 5000 intrări
documentCache Cache pentru documentele încărcate 10000 intrări

Thread pool

Configurarea thread pool-ului asigură că SOLR poate procesa simultan un număr optim de interogări fără a supraîncărca resursele serverului.

Parametru Valoare Descriere
maxThreadCount 100 Numărul maxim de thread-uri pentru interogări
maxQueueSize 50 Dimensiunea maximă a cozii de așteptare
keepAlive 120s Timpul de menținere activă a thread-urilor inactive

Query time optimization

  • Query parsing — utilizarea parser-ului optim pentru tipul de interogare
  • Field boosting — prioritizarea câmpurilor relevante în rezultate
  • Highlighting — evidențierea termenilor căutați în rezultate
  • Facet caching — cache pentru valorile de faceting

Monitorizare performanță

Monitorizarea performanței este implementată prin colectarea metricilor cheie și afișarea acestora într-un dashboard dedicat:

  • QPS — queries per second (interogări pe secundă)
  • Average query time — timpul mediu de răspuns
  • Cache hit ratio — rata de succes a cache-ului
  • Index size — dimensiunea indexului
  • Heap usage — utilizarea memoriei JVM

Alerting la degradare

Sistemul de alerting notifică echipa atunci când performanța scade sub pragurile stabilite:

Metrică Prag warning Prag critical
Query time mediu > 200ms > 500ms
Cache hit ratio < 80% < 60%
Heap usage > 75% > 90%
Error rate > 1% > 5%

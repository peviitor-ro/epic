ID: FEAT-016 Feature
JURNAL DE AUDIT

Prezentare generală

Jurnalul de audit este un sistem de înregistrare a tuturor operațiunilor de scriere efectuate pe platforma peviitor.ro. Fiecare modificare a datelor este documentată cu detalii complete despre cine a efectuat operațiunea, ce a fost modificat și când s-a întâmplat, asigurând trasabilitatea completă a acțiunilor.

Operațiuni înregistrate

Jurnalul de audit înregistrează toate operațiunile de scriere efectuate asupra datelor din platformă:

Operațiune Exemple Detalii înregistrate
Creare Job nou, companie nouă, utilizator nou Date complete introduse, sursa cererii
Modificare Actualizare job, schimbare setări, editare profil Valori vechi vs. valori noi, timestamp
Ștergere Ștergere job, dezactivare cont, ștergere document Date șterse, motivul (dacă există)
Acces Descărcare date, export, acces neautorizat Tipul de acces, entitatea vizată

Formatul intrării din jurnal

Fiecare intrare din jurnalul de audit conține patru elemente esențiale:

  1. Cine — ID-ul utilizatorului sau al cheii API care a efectuat operațiunea
  2. Ce — Tipul operațiunea (create/update/delete) și tipul resursei afectate
  3. Când — Timestamp-ul UTC la care s-a produs operațiunea
  4. Modificări — Detalii despre valorile vechi și cele noi (diferența)
Exemplu de intrare: { "who": "user_abc123", "what": "update", "resource": "job_789", "when": "2026-07-15T14:30:00Z", "changes": { "title": ["Job vechi", "Job nou"] } }

Retenție și căutare

Jurnalul de audit beneficiază de o perioadă de reținere de 1 an de la data înregistrării. Intrările mai vechi de 1 an sunt arhivate automat și șterse din baza de date principală.

  • Căutare — jurnalul este complet căutabil după utilizator, tip operațiune, resursă și interval de timp
  • Filtrare — posibilitatea de a filtra după rol (admin, comp-admin, viewer) sau tip de acțiune
  • Export — posibilitatea de a exporta rezultatele în format CSV sau JSON
  • Alerte — notificări automate pentru operațiuni suspecte (acces neautorizat, ștergeri în masă)

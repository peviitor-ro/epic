ID: FEAT-002 Feature
SURSE GRATUITE DE VERIFICARE

Prezentare generală

Pentru a verifica datele despre o companie din România există mai multe surse gratuite puse la dispoziție de instituții publice și platforme private. Fiecare sursă oferă un set diferit de informații, cu grade diferite de acuratețe și limitări proprii.

Acest feature documentează toate sursele disponibile gratuit, datele pe care le oferă, limitările fiecăreia și un ghid simplu de decizie pentru a alege sursa potrivită în funcție de nevoia specifică.

Când să folosești fiecare sursă

Alegerea sursei potrivite depinde de tipul de verificare pe care dorești să îl efectuezi:

  • Verificare rapidă a existenței — Cuifirma.ro sau Targetare.ro (căutare simplă, instantanee)
  • Stare fiscală — Demoanaf.ro sau ANAF (surse oficiale, date de încredere)
  • Date oficiale complete — ONRC (sursa primară, cea mai actualizată)
  • Validare în masă — ANAF API (singura sursă cu API programatic, max 100 CUI-uri/request)
  • Date financiare — Termene.ro (rapoarte detaliate contra cost)
  • Date de bază gratuite — Listafirme.ro (informații generale fără cost)

Recomandări pentru EPIC

Pentru peviitor.ro, strategia recomandată este:

  1. Primar — ANAF API pentru validare automată în masă (FEAT-003: ANAF Sync)
  2. Secundar — ONRC prin data.gov.ro pentru importul inițial de companii (FEAT-004: ONRC Import)
  3. Tertiar — Cuifirma.ro / Demoanaf.ro pentru verificări punctuale manuale

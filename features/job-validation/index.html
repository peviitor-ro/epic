ASOCIAȚIA OPORTUNITĂȚI ȘI CARIERE
ID: FEAT-008 Feature
VALIDARE JOB

Prezentare generală

În cadrul peviitor.ro, fiecare anunț de angajare trebuie să respecte un set de reguli de validare înainte de a fi indexat în motorul de căutare. Acest feature definește regulile de validare pentru fiecare câmp din modelul Job, asigurând calitatea și coerența datelor.

Validarea se realizează la momentul primirii datelor prin API, înainte ca job-ul să fie salvat în SOLR. Orice încălcare a regulilor returnează un răspuns de eroare detaliat.

Reguli de validare per câmp

Câmp Regulă Detalii
url URL valid Format URL complet, cu protocol (https://). trebuie să pointing către un job real
title Max 200 caractere, fără HTML Fără taguri HTML, fără caractere speciale periculoase. Max 200 de caractere
company Must match Company.company Denumirea trebuie să corespundă exact cu o companie existentă în sistem
cif Must match Company.id Exact 8 cifre, fără prefix RO, trebuie să existe în baza de date
location string[] Array de stringuri, cel puțin o locație obligatorie
tags string[], max 20 items, fără diacritice Array de stringuri, max 20 de elemente, fără diacritice românești
workmode Enum: remote / on-site / hybrid Una dintre cele trei valori permise, lowercase
salary Format: MIN-MAX CURRENCY Interval salarial cu monedă. Ex: 1000-2000 RON
date ISO8601 UTC Data publicării în format ISO8601 cu timezone UTC
status Enum: scraped / tested / published / verified Starea job-ului în ciclul de viață

Exemple de validare

Job valid

URL: https://company.com/careers/job-123
Title: Senior Software Engineer
Company: DANTE INTERNATIONAL SRL
CIF: 12345678
Location: București, Cluj-Napoca
Tags: javascript, react, nodejs
Workmode: hybrid
Salary: 5000-8000 RON
Date: 2026-01-15T10:00:00Z
Status: published

Job invalid

URL: nu-este-url-valid
Title: <script>alert('xss')</script>
Company: COMPANIE INEXISTENTA
CIF: 123
Workmode: remote-office

Eroare returnată: URL invalid, titlu conține HTML, companie inexistentă, CIF invalid (nu are 8 cifre), workmode invalid.

Lanțul de validare

Validarea se desfășoară în următoarea ordine:

  1. Validare URL — verificare format URL valid
  2. Validare title — verificare lungime max 200, fără HTML
  3. Validare company — verificare existență în sistem
  4. Validare CIF — verificare format și existență
  5. Validare location — verificare că este array nevid
  6. Validare tags — verificare max 20 items, fără diacritice
  7. Validare workmode — verificare enum permis
  8. Validare salary — verificare format MIN-MAX CURRENCY
  9. Validare date — verificare format ISO8601 UTC
  10. Validare status — verificare enum permis

Comportament la eroare

Dacă oricare dintre validări eșuează, API-ul returnează un răspuns cu status 400 Bad Request și un body JSON care conține lista de erori. Fiecare eroare include câmpul afectat, tipul erorii și un mesaj descriptiv.

Job-urile cu erori nu sunt indexate în SOLR până când toate câmpurile nu sunt corecte.

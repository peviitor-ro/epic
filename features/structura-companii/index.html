STRUCTURA COMPANIEI

Prezentare generală

În cadrul peviitor.ro, o companie este mai mult decât un nume pe un anunț de angajare. Fiecare entitate care publică locuri de muncă are o identitate legală, o identitate comercială, o poziție într-o structură corporatistă și un scraper asociat care colectează automat anunțurile sale.

Acest feature definește modelul complet al unei companii în sistem: de la denumirea oficială din Registrul Comerțului, până la repo-ul GitHub care face scraping automat al job-urilor sale.

Identitatea legală — Denumirea oficială

Orice companie din România are o denumire oficială (denumire legală) înregistrată la Oficiul Național al Registrului Comerțului (ONRC). Aceasta apare pe toate documentele oficiale: facturi, contracte, acte constitutive, declaratii fiscale.

Denumirea oficială este identificată prin CIF/CUI (Codul de Identificare Fiscală), un număr de 8 cifre fără prefix RO. Acesta este identificatorul unic al companiei în sistem.

Exemplu

eMAG este brandul cunoscut de public. Denumirea oficială a firmei este Dante International SRL. CIF-ul acesteia permite identificarea unică în sistem.

Identitatea comercială — Brandul

Un brand este numele, logo-ul sau 组合ul de elemente sub care o companie este cunoscută de public. Brandul este frecvent diferit de denumirea oficială.

Diferența dintre brand și denumire oficială

Aspect Denumire oficială Brand
Scop Identificare legală Identificare comercială
Cine o stabilește La înmatriculare (ONRC) De companie (marketing)
Unde apare Facturi, contracte, acte oficiale Publicitate, site, ambalaje
Poate fi schimbată Da, cu formalități legale Da, mai ușor
Unicitate O singură denumire oficială O firmă poate avea mai multe branduri

Structura de grup

O companie poate face parte dintr-un grup — o structură formată din mai multe entități juridice legate prin relații de control, proprietate sau administrare comună.

Cum se formează un grup

  • Prin achiziție — o companie cumpără alta (ex: eMAG a cumpărat Fashion Days)
  • Prin participații — o companie deține procente din capitalul alteia
  • Prin înființare — o companie creează o subsidiară nouă pentru un scop specific

Scraper-ul asociat

Fiecare companie din peviitor.ro are asociat un scraper — un repository GitHub care conține codul de scraping automat responsabil cu colectarea anunțurilor de angajare ale companiei respective.

Ce este un scraper

Un scraper este un script automatizat care:

  • Accesează periodic pagina de cariere a companiei
  • Extrage toate anunțurile de angajare disponibile
  • Le trimite către API-ul peviitor.ro prin endpoint-ul POST /api/v1/job
  • Actualizează statusul job-urilor (noi, modificate, șterse)

Structura unui scraper

Componentă Descriere
Repo GitHub Fiecare scraper are propriul repo în organizația peviitor-ro de pe GitHub
Cod sursă Script Python sau alt limbaj care face scraping-ul efectiv
Configurare URL-ul paginii de cariere, intervalul de rulare, regex-uri pentru parsing
GitHub Actions Workflow automat care rulează scraper-ul la interval configurat
Logging Înregistrarea operațiilor pentru audit și depanare

Flow-ul de colectare

  1. Trigger — GitHub Actions rulează scraper-ul la intervalul configurat (ex: la fiecare 6 ore)
  2. Scraping — scriptul accesează pagina de cariere a companiei și extrage job-urile
  3. Validare — fiecare job este validat conform regulilor din API (URL valid, titlu ok, CIF corect)
  4. Îmbogățire — API-ul completează automat datele companiei din ANAF și surse AI
  5. Insert/Update — job-urile sunt trimise prin API și indexate în SOLR
  6. Ștergere — job-urile care nu mai apar pe site-ul companiei sunt marcate ca inactive

Relația dintre scraper și companie

Relația dintre o companie și scraper-ul său este unu la unu. Fiecare scraper este dedicat unei singure companii și este identificat prin câmpul scraperFile din modelul de date al companiei.

Această arhitectură permite:

  • Izolare — o eroare într-un scraper nu afectează celelalte
  • Responsabilitate — fiecare voluntar poate mentine scraper-ul unei companii
  • Scalabilitate — se pot adăuga noi companii prin simpla creare a unui scraper
  • Audit — istoricul complet al colectării este disponibil în GitHub

Modelul de date complet

Tabelul complet al câmpurilor care descriu o companie în cadrul sistemului:

Câmp Tip Obligatoriu Descriere
id string Da CIF/CUI, exact 8 cifre, fără prefix RO
company string Da Denumirea oficială din Registrul Comerțului, uppercase, cu diacritice
brand string Nu Numele comercial sub care este cunoscută (ex: ORANGE, EPAM)
group string Nu Grupul din care face parte (ex: Orange Group, EPAM Systems)
status string Nu activ / suspendat / inactiv / radiat
location string[] Nu Orașul/orașele unde compania are sedii
website string[] Nu URL-urile site-urilor oficiale
career string[] Nu URL-urile paginilor de carieră
lastScraped string Nu Data ultimei colectări, format ISO8601
scraperFile string Nu Numele repo-ului scraper de pe GitHub

Surse de date

Datele despre companii provin din următoarele surse:

  • ONRC — Registrul Comerțului, seturi de date deschise pe data.gov.ro
  • ANAF API — webservicesp.anaf.ro, max 100 CUI-uri per request
  • Scrapere directe — voluntarii adaugă companii prin scraper-e dedicate
  • AI agentic (Web Search) — agent AI identifică automat website, pagină de carieră, brand și grup

ID: FEAT-007 Feature
AUTOMATION & SCHEDULING

Prezentare generală

Automatizarea proceselor de colectare și actualizare a datelor prin GitHub Actions. Acest feature definește orchestrarea tuturor proceselor de sincronizare, import, îmbogățire și scraping din cadrul peviitor.ro, asigurând că datele rămân mereu actualizate fără intervenție manuală.

Componente

Componentă Frecvență Descriere

ONRC Import Lunar Import date din Registrul Comerțului de pe data.gov.ro (FEAT-004)

Scrapere La 6 ore Colectare automată anunțuri de angajare de pe site-urile companiilor

GitHub Actions Workflows

Fiecare componentă rulează ca un workflow separat în GitHub Actions, cu configurare proprie de trigger, schedule și monitoring.

Configurare workflow

  • Trigger — cron schedule pentru rulare automată, manual dispatch pentru rulări manuale
  • Schedule — exprimat în format cron UTC
  • Monitoring — verificare stare workflow la fiecare rulare
  • Alerting — notificare Discord la eșec

Logging și audit

Toate operațiile sunt înregistrate pentru trasabilitate completă:

  • Logs de rulare — outputul fiecărei rulări este salvat în GitHub Actions logs
  • Metrics — număr de companii procesate, actualizări, erori
  • Istoric — fiecare rulare poate fi inspectată retroactiv

Error handling

  • Retry — la eșec temporar, se reîncearcă automat de maxim 3 ori
  • Fallback — dacă o sursă eșuează, se continuă cu celelalte
  • Notificări Discord — la eroare critică, se trimite mesaj în canalul de Discord dedicat

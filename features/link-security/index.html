ID: FEAT-019 Feature
SECURITATE LINKURI

Prezentare generală

Securitatea linkurilor este un sistem de scanare și verificare a URL-urilor găsite în conținutul joburilor de pe peviitor.ro. Sistemul integrează servicii externe de reputație pentru a detecta și bloca automat linkurile care direcționează către conținut malware, phishing sau alte amenințări cibernetice.

Integrări externe

Serviciu Utilizare Frecvență
Google Safe Browsing Detectarea site-urilor de phishing, malware și software nedorit La fiecare adăugare/modificare
VirusTotal Scanarea completă a URL-urilor cu peste 70 de motoare de detecție La fiecare adăugare/modificare

Scanare automată

Fiecare link din conținutul unui job este scanat automat înainte de a fi indexat. Sistemul verifică URL-ul împotriva bazelor de date de reputație și aplică acțiuni în funcție de rezultat.

  1. Extragere linkuri — toate URL-urile sunt extrase din descrierea și conținutul jobului
  2. Verificare reputație — fiecare URL este verificat prin Google Safe Browsing și VirusTotal
  3. Evaluare risc — scorul de risc este calculat pe baza rezultatelor de la ambele servicii
  4. Acțiune automată — link-urile cu risc ridicat sunt blocate automat
  5. Înregistrare — rezultatul scanării este înregistrat în jurnalul de audit

Blocare automată

Link-urile identificate ca periculoase sunt blocate automat și nu sunt accesibile utilizatorilor. Compania care a publicat jobul este notificată despre blocare și poate solicita o re-verificare.

  • Blocare imediată — linkul este marcat ca blocat și ascuns din interfață
  • Notificare companie — compania primește un email cu detalii despre motivul blocării
  • Proces de apel — compania poate contesta blocarea printr-un formular dedicat
  • Re-verificare — după remediere, linkul poate fi re-verificat și deblocat

Re-verificare periodică

Linkurile sunt supuse unei re-verificări periodice pentru a detecta situațiile în care un link inițial sigur devine periculos ulterior (compromis ulterior — compromised after initial check).

Interval Acțiune
Săptămânal Re-verificarea tuturor linkurilor blocate pentru a detecta deblocările posibile
Lunar Re-verificarea întregului index de linkuri active
La cerere Re-verificare imediată la solicitarea companiei sau a unui utilizator

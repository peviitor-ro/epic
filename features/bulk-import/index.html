ID: FEAT-012 Feature
IMPORT ÎN MASĂ

Prezentare generală

Pentru companiile cu un număr mare de poziții deschise, peviitor.ro oferă posibilitatea importului în masă al anunțurilor de angajare. Acest feature definește procesul de upload, validare și import al datelor în batch, cu tracking al progresului, raportare de erori și posibilitatea de rollback.

Format de input

Format Descriere Limitări
CSV Fișier CSV cu header, encoding UTF-8 Max 10.000 rânduri, separator virgulă
JSON Array de obiecte Job în format JSON Max 10.000 obiecte, max 50MB

Procesul de import

  1. Upload — fișierul CSV/JSON este uploadat prin API
  2. Parsare — fișierul este parsat și transformat în listă de job-uri
  3. Validare — fiecare job este validat conform regulilor din FEAT-008
  4. Deduplicare — verificare duplicate conform FEAT-011
  5. Asociere companie — matching automat conform FEAT-013
  6. Indexare — job-urile valide sunt indexate în SOLR
  7. Raport — generare raport cu rezultatele importului

Tracking al progresului

Pentru importurile mari, sistemul oferă tracking în timp real al progresului:

Câmp Descriere
total Numărul total de job-uri din fișier
processed Numărul de job-uri procesate
valid Numărul de job-uri valide indexate
invalid Numărul de job-uri cu erori
duplicates Numărul de duplicate detectate
status pending / processing / completed / failed

Raportare de erori

Fiecare eroare de import include:

  • Linia — numărul rândului din fișierul sursă
  • Câmpul — câmpul care a cauzat eroarea
  • Tipul — tipul erorii (validare, duplicate, asociere)
  • Mesajul — descrierea erorii

Rollback

În cazul în care un import eșuează parțial sau total, sistemul oferă posibilitatea de rollback — anularea tuturor modificărilor făcute în timpul importului. Rollback-ul este disponibil timp de 24 de ore de la finalizarea importului.

ID: FEAT-032 Feature
PIPELINE ÎMBOGĂȚIRE ANAF

Prezentare generală

Pipeline-ul de îmbogățire ANAF este un proces automatizat de completare a datelor companiilor utilizând informații din surse multiple. Pipeline-ul preia datele de bază (companie, CIF, status, locație) din ANAF și le completează cu informații suplimentare din SOLR și căutări web AI pe peviitor.ro.

Surse de date

Sursă Câmpuri preluate Descriere
ANAF company, cif, status, location Date oficiale de identificare fiscală și juridică
SOLR / AI Web Search brand, group, website, career Date de marketing, apartenență la grup, site oficial și pagina de cariere

Fluxul de îmbogățire

  1. Extragere date ANAF — se preiau informațiile de identificare fiscală
  2. Căutare în SOLR — se verifică dacă există date anterioare indexate
  3. Căutare AI web — dacă lipsesc câmpuri, se face o căutare pe site-ul companiei
  4. Fuziune date — toate sursele sunt combinate într-un singur obiect Company
  5. Salvare index — datele îmbogățite sunt scrise în SOLR și în baza de date

Câmpuri îmbogățite

  • brand — numele comercial al companiei (dacă diferă de denumirea juridică)
  • group — grupul sau holding-ul din care face parte
  • website — adresa site-ului oficial
  • career — link-ul către pagina de cariere/jobs a companiei

Programare

Pipeline-ul rulează automat la fiecare 24 de ore și, de asemenea, la primirea unui nou anunț de angajare. Actualizările sunt incremental, procesând doar înregistrările noi sau modificate.

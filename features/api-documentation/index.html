ID: FEAT-036 Feature
DOCUMENTAȚIE API

Prezentare generală

Documentația API este resursa principală pentru dezvoltatorii care integrează cu platforma peviitor.ro. Aceasta este generată automat în format OpenAPI/Swagger și conține descrierea completă a endpoint-urilor, modelelor de date și exemple de utilizare.

Structura documentației

Secțiune Conținut
OpenAPI/Swagger Specificația completă în format OpenAPI 3.0
Endpoint-uri Lista completă a endpoint-urilor cu metode HTTP, parametri și răspunsuri
Modele JSON Definițiile modelelor Job și Company cu toate câmpurile
Exemple Cereri și răspunsuri exemplificative pentru fiecare endpoint
Ghid companii Instrucțiuni pas cu pas pentru integrarea companiilor

Endpoint-uri principale

Metodă Endpoint Descriere
GET /api/jobs Listarea job-urilor cu filtrare și paginare
POST /api/jobs Crearea unui nou job
GET /api/jobs/{id} Detaliile unui job specific
PUT /api/jobs/{id} Actualizarea unui job existent
DELETE /api/jobs/{id} Ștergerea unui job
GET /api/companies Listarea companiilor

Modele JSON

Job

  • id — identificator unic al job-ului
  • title — titlul anunțului
  • url — link-ul către sursa originală
  • company — obiect cu datele companiei
  • location — locația job-ului
  • published_at — data publicării

Company

  • id — identificator unic al companiei
  • cif — Codul de Identificare Fiscală
  • name — denumirea companiei
  • status — statusul juridic (activ, inactiv)
  • location — sediul companiei
  • website — site-ul oficial

Ghid pentru companii

Documentația include un ghid dedicat companiilor care explică pas cu pas cum să:

  • Își creeze un cont și obțină cheia API
  • Trimite un job nou prin API
  • Gestioneze job-urile existente
  • Interpreteze codurile de eroare

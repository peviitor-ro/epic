ID: FEAT-047 Feature
API KEY MANAGEMENT

Prezentare generală

API Key Management este mecanismul prin care peviitor.ro gestionează cheile de autentificare pentru fiecare companie integrată. Fiecare companie primește o cheie unică, cu drepturi limitate la propriile date, și este obligată să o rotaționeze periodic conform politicii de securitate.

Acest feature implementează cerințele definite în EPIC-017, oferind lifecycle-ul complet al unei chei API.

Lifecycle-ul unei chei API

Fază Acțiune Rezultat
Creare Compania se înregistrează prin POST /api/v1/auth/register Se generează cheie nouă cu status active
Activă Cheia este folosită pentru autentificare Request-urile sunt procesate normal
Rotație Se generează cheie nouă (automat sau manual) Cheia veche devine rotated (7 zile overlap)
Revocare Compania solicită revocarea sau expirarea Cheia devine revoked și nu mai funcționează

Structura cheii API

Format: pv_[company_id]_[random_64_chars]
Exemplu: pv_12345678_a1b2c3d4e5f6... (64 chars)

Cheia conține trei componente:

  • pv — prefixul platformei (peviitor)
  • company_id — CIF-ul companiei (8 cifre)
  • random_64_chars — șir aleatoriu hex (128 biți de entropie)

Endpoint-uri

Metodă Endpoint Descriere
POST /api/v1/auth/register Înregistrare companie + generare cheie inițială
POST /api/v1/auth/rotate Rotație manuală a cheii (generează cheie nouă)
DELETE /api/v1/auth/revoke Revocarea cheii curente
GET /api/v1/auth/status Statusul cheii curente + dată expirare

Stocare securizată

Cheile nu sunt stocate în text clar. Sistemul folosește:

  • Hash bcrypt — pentru verificarea la autentificare
  • Criptare AES-256 — pentru stocare în repaus
  • Secret isolation — cheile sunt stocate separat de datele companiei
  • Access control — doar sistemul de autentificare accesează cheile

Notificări

Eveniment Notificare Timing
Cheie generată Email + Discord Instant
Expirare apropiată Email + Discord 14 zile înainte
Cheie rotată Email + Discord Instant
Cheie revocată Email + Discord Instant

CĂUTARE FULL-TEXT

Prezentare generală

Căutarea full-text este mecanismul principal prin care candidații pot găsi job-uri relevante pe peviitor.ro. Sistemul utilizează SOLR cu un analizor specializat pentru limba română, asigurând rezultate precise și relevante pentru interogările utilizatorilor.

Analizor românesc

Configurarea căutării full-text include un analizor specializat pentru limba română care procesează textul înainte de indexare și interogare:

  • Tokenizer — împarte textul în token-uri
  • Filtru lowercase — convertește totul la litere mici
  • Filtru diacritice — gestionează transformarea diacriticelor
  • Stop words — elimină cuvintele comune fără semnificație
  • Stemming — reducerea cuvintelor la rădăcină

Câmpuri indexate în _text_

Câmp sursă Descriere Prioritate
title Titlul poziției Crescută
company_name Numele companiei Normală
location Locația job-ului Normală
description Descrierea postului Scăzută

Păstrarea diacriticelor

Sistemul păstrează diacriticele pentru a asigura căutări corecte în limba română. Caractere precum ă, î, ș, ț sunt indexate și căutate corect, permițând candidaților să găsească rezultate relevante chiar și atunci când caută cu diacritice sau fără.

Exemple de interogări

Interogare Rezultat așteptat
programator Toate job-urile care conțin „programator" sau derivate
București Job-urile din București, indiferent de forma diacritică
developer front-end Job-uri care conțin „developer" SAU „front-end"

ID: FEAT-018 Feature
BACKUP AUTOMAT

Prezentare generală

Backup-ul automat este procesul de salvare periodică a datelor din clusterul SOLR, asigurând recuperarea rapidă în cazul unui dezastru sau a unei erori de integritate. Sistemul rulează automat, fără intervenție umană, și include stocare în locații externe pentru protecție maximă.

Snapshot-uri zilnice SOLR

Clusterul SOLR generează snapshot-uri zilnice ale indexului, capturând starea completă a datelor la momentul creării. Fiecare snapshot este un punct de restaurare independent.

Parametru Valoare
Frecvență Zilnică, la ora 02:00 UTC
Metodă SOLR Core Admin — Create Snapshot
Compresie gzip pentru reducerea spațiului
Verificare integritate Checksum SHA-256 pentru fiecare snapshot

Retenție și stocare

Politica de reținere garantează disponibilitatea backup-urilor pe o perioadă de 30 de zile, cu stocare în locații externe pentru protecție împotriva dezastrului fizic.

  • Retenție 30 zile — snapshot-urile mai vechi de 30 de zile sunt șterse automat
  • Stocare off-site — copii ale backup-urilor sunt stocate într-o locație geografic diferită
  • criptare — toate backup-urile sunt criptate cu AES-256 în repaus și în tranzit
  • Verificare automată — backup-urile sunt verificate automat pentru integritate la fiecare creare

Testare lunară de restaurare

Pentru a garanta funcționalitatea backup-urilor, se efectuează o testare lunară de restaurare într-un mediu izolat, verificând că datele pot fi recuperate complet și corect.

  1. Selectare snapshot — se alege aleatoriu un snapshot din ultimele 30 de zile
  2. Restaurare în mediu izolat — snapshot-ul este restaurat pe un cluster de test
  3. Validare date — se verifică integritatea și completitudinea datelor restaurate
  4. Test funcțional — se rulează interogări de bază pentru a confirma funcționalitatea
  5. Raport — rezultatul testului este documentat și trimis echipei tehnice
